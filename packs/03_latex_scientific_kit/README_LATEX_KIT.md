# Kit de Automatizacion LaTeX IEEE & Figuras Cientificas

Plantilla profesional en LaTeX y modulo Matplotlib para presentar informes tecnicos, laboratorios y tesis con estetica editorial limpia (tipografia Computer Modern, tablas `booktabs`, cajas sobrias y graficas sin solapamiento).

## Archivos incluidos
- `engineering_report.cls` y `engineering_theme.sty`: Clase y tema LaTeX listos para usar.
- `plantilla_informe_ingenieria.tex`: Plantilla compilable con portada, ecuaciones, tablas y cajas tecnicas.
- `logo_studio.png`: Emblema tecnico geometrico de muestra (puedes reemplazarlo por cualquier otro PNG).
- `scientific_figure_style.py` y `demo_figuras_editorial.py`: Modulo Python para exportar figuras a 300 DPI con verificacion automatica de solapamientos.
